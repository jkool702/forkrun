# STAGE0 Amendment — from falsification gate to evidence instrument

**Status:** decision record. The v1.3 plan's Stage 0 (§2) is amended as
below; the plan text itself is frozen (architecture of record) and is not
edited — this file carries the delta.

## What changed

v1.3 defined Stage 0 as a *falsification gate*: measure the Python API
surface against real incumbents, proceed on a compelling niche, stop on
nothing-anywhere. **The stop branch is removed. The proceed decision is
made unconditionally, now, by the owner.** Work order W-S0 builds the
harness anyway — re-purposed from decision instrument to the project's
evidence layer (localization numbers, honest-claims tables, per-niche
positioning).

## The owner's reasoning (binding)

1. **The gate cannot answer the adoption question.** Adoption depends on
   multi-socket NUMA behavior, pipeline-level fault-tolerance value, and
   team-sociology factors — all outside any single-machine benchmark's
   reach. A gate that cannot measure the decision criterion is ritual.
2. **No competing lead.** The opportunity-cost analysis finds nothing else
   that makes forkrun economically relevant; the stop branch was vacuous —
   there is nowhere else to spend the attention.
3. **Cost structure inverted.** AI-accelerated implementation against a
   specification-complete plan makes the at-risk resource *supervision
   attention*, not engineering calendar. A gate costing days to protect
   weeks of accelerated work no longer trades correctly.
4. **Iteration count, not binary.** The value thesis converges by iterating
   against sharp feedback. The harness exists to *sharpen the feedback* —
   each number points at a subsystem.

## What is preserved from the gate design

Everything structural: per-niche multi-axis measurement, real incumbents
on the same machine and day, the 3–5× strong-win bar as a *positioning*
threshold (which niches the docs lead with), empirical incumbent-specific
fault tables with no generalized claims, the SIGSEGV injection harness,
mandatory hardware disclosure, UNMEASURED-with-reason discipline, and the
§3.0-prerequisite rule (the gate measures the shipping surface).

## Residual risk (named, accepted)

Weeks of supervision attention if the thesis is wrong. Accepted: no
competing lead exists, and the evidence layer shortens every subsequent
iteration whether or not the thesis holds — the harness pays for itself
as localization infrastructure from the first regression it bisects.

## Ordering note

W-S0 runs before Stage 1 work begins but touches zero product code; the
substrate numbers it records (locally-built v3.5.2-dev blob, provenance
logged per run) become Stage 4's baseline context when the Python
frontend lands as a new row-set in the same persistent table.
